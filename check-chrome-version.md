# Check Your Chrome Version

Please check your Chrome version:

1. In Chrome, click the 3-dot menu (⋮) in top-right
2. Go to: Help → About Google Chrome
3. Look for version number (e.g., "Version 131.0.6778.86")

**What version do you have?**

If Chrome < 91: ES modules not supported (need workaround)
If Chrome 91-92: Partial support (some bugs)
If Chrome 93+: Full support (should work)
